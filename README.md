# Aikya's GCSE 2027 Grade 9 Plan

A static site with the full plan, the five question banks, the mock exam schedule and 347 flashcards.

| Page | File |
| --- | --- |
| Home | `index.html` |
| The plan | `plan.html` |
| Mock exams | `mocks.html` |
| Maths, English, Science, History, PE & 3D Design banks | `maths.html`, `english.html`, `science.html`, `history.html`, `pe-3d.html` |
| Flashcards | `flashcards.html` |

## Publish with GitHub Pages
Push to `main`. The workflow in `.github/workflows/pages.yml` deploys the site to
`https://<your-username>.github.io/gcse-plan/`.
(First time only: repo **Settings → Pages → Source: GitHub Actions**.)

## Preview in a Codespace
**Code → Codespaces → Create codespace on main.** The site starts automatically on port 8000
and opens in a preview tab.

Ticks and flashcard progress are saved in each browser's local storage.
